# 故事质量评分卡

> `dramakit quality` 回答的问题：**这个本子的结构特征齐不齐。**
> `dramakit scan` 回答的问题：**这张分镜表合不合格。**
> 两把尺子量的是两个东西，不要互相替代。

## 一、先说清楚它量不到什么

戏好不好，最终不可机械判。演技、共情、真实感、审美、"这个题材有没有人看"，
一条都量不出来。这里量的全是**代理指标**——爆款短剧反复出现的结构特征。

所以：

- 它是**参考分，不是门槛**，不拦稿。scan 的阻断/警告结论不受它影响。
- 100 分不代表好看，只代表"该有的结构特征都有"。
- 分数低也不代表必须重写，但**值得回头看一遍**是哪儿空了。

## 二、五个维度

满分 100。`≥80` 强，`60-79` 可打磨，`<60` 回炉。

| 维度 | 权重 | 怎么量 | 满分条件 | 量不到什么 |
|---|---|---|---|---|
| 事件密度 | 25 | 含"变化动词"的镜头占比 | 占比 ≥50% | 事件重不重要 |
| 呼应结构 | 25 | 远距重复的 token 数（埋点→回收） | ≥3 处 | 埋得巧不巧 |
| 空间变化 | 20 | **逐镜**取场景名后的 distinct 数 | ≥3 处 | 场景之间有没有关系 |
| 点题自律 | 15 | "旁白/字幕 + 主题句"同时出现的镜数 | 0 处 | 演出来的主题好不好 |
| 冲突面 | 15 | **真人物**数（≥2 得 8）+ 对抗动作镜数（≥2 得 7） | 两项都达标 | 冲突有没有张力 |

**事件密度**量的是"事情在发生"。两人坐着说完全场，这里是 0。
词表收的是**实际会写出来的说法**（"门被推开"而不是只收"推门"）——
初版词表漏了"门被推开/闪了/空了"，两个好样本被打成 2/24 与 4/32，
判据静默失灵且不报错。

**空间变化**只收**空间**，不收家具。沙发、货架、柜台、收银曾经在表里，
结果一个便利店示例被数成 6 处场景（便利店/收银/收银台/街上/货架/门口）——
家具换了不算"戏换了地方"。

★ **空间变化必须逐镜取，不能扫全文。**（v0.6.0 修正）
初版扫正文，于是正文里写一句"场景：客厅、卧室、厨房"这种清单就能拿满分——
实测一张 8 镜全在客厅的表，正文列三个场景名，空间变化直接 20/20。
这是"按名词查表"的翻车：**查到了词，却不是这个维度要的东西**。
空间变化量的是"这一镜发生在哪儿"，所以只能逐镜看。

**点题自律**要求叙述手段（旁白/字幕/屏幕字/标题卡）**与**主题句同时出现
才算一次点题。只有"字幕：第三天"不算，那是信息标注。
好短剧演出来，不说出来；说出来的每处扣 5 分。

**冲突面**的人物数来自"谁在画面"列。7 列工作表没有这一列 →
**人物数不可验，该半分直接不给，并在明细里注明**。
不把"画面里没人名"当成"只有一个角色"。

★ **占位词与数量描述必须剔掉，否则人物数虚高。**（v0.6.0 修正）
"空镜""两人""三人同框""路人""众人"这些不是人名。初版不剔，实测
《十七楼》明明只有周牧与女人两人，却被数成"4 个人物"，冲突面的人物分
直接拿满 15/15。这跟"胶水词混进呼应"是同一族病：
**查到了词，但那个词不是这个维度要的东西。**
剔完实测：十七楼仍是 14/15 达标，但数据是真的了。

## 三、呼应结构：最容易误判的一维

不靠词表，靠**远距重复**。关键 token（时刻/日期/物件/昵称）在相隔很远的
两个镜头里再次出现，就是一次"埋点→回收"。

为什么不用"反转词计数"：台词措辞追不上。初版用"没想到/原来/真相"词表，
两个好样本被打成 0/3 幕与 1/3 幕，而判据不报错。回声对写法免疫——
"三年前，今天"与"23:47"能被同一把尺子量到。

### 四类伪回声，必须排掉，否则任何剧本都满分

| 类型 | 例子 | 排除规则 |
|---|---|---|
| 胶水词 | 主角名、主语几乎每镜出现 | 命中镜数占比 > `max_shot_ratio`（0.30）即弃 |
| 贴身重复 | "十一号"连说两镜 | 时间跨度 < `min_span_ratio`（0.25）即弃 |
| 世界观词 | 场景本身（收银台/货架/屏幕）隔几镜出现一次 | 要求首次命中在前 45%、末次命中在后 55% 之后 |
| 虚词噪音 | "的了吧"组成的候选词 | 命中 `stopchars` / `stopwords` 即弃 |

世界观词那条最关键：**"世界一直在"不是"埋点回收"**。少了这条，
收银台这种每隔几镜就出现的场景词会被全算成呼应。

### 同源切片必须合并

滑窗会从"收银台"里切出"收银""银台"，三者命中同一批镜头——
那是**同一个现象**，不是一个现象算三处。合并判据：命中位置集合的
Jaccard 相似度 ≥ `merge_jaccard`（0.6）即归为一簇，簇内取最长词作代表。

不合并会虚胖：实测一个便利店示例被数成 28 处呼应，全绿失真。

### 一个试过但否掉的旋钮

`require_line = true` 要求埋点"说出口过"（token 至少命中一次台词列）。
听起来对，实测得不偿失：

- 好处：坏样本（两人对坐说完全场）呼应分从 25 → 0；
- 代价：好样本也塌了——便利店 100→83、地铁 92→67，
  因为"收据/伞架"这类**真道具埋点只写在画面列**。

坏样本靠事件密度/空间变化/点题三维已经压到 42 回炉，不需要在这里牺牲召回。
开关留着，默认关，给"只认台词埋点"的严格场景用。

## 四、已知盲区（诚实记录）

1. **纯对白戏的呼应分会虚高。** 坏样本里"杯子/两个人/窗外"在画面列重复，
   照样拿满 25 分。它靠其余四维压到 42 回炉——所以**不要只看单维分数**。
2. **单人短剧的冲突面必然低。** 《最后一班地铁》全片一个人，
   冲突面 7/15 是真实短板，不是误判。
3. **7 列工作表的人物数不可验。** 该半分不给并注明，这是设计，不是 bug。
4. **n-gram 会切出"头看"这类残片**（"回头看向"的 2-gram）。
   已在 stopwords 里排了一批高频动作词，但排不干净。
5. **它量不到"题材行不行"。** 这条最要紧：**题材不行，剧本怎么改都是白改**。
   一个结构特征全齐的本子照样可能没人看。评分卡不是选题判据。
6. **空间变化要求场景名写进镜头列。** 场景名只写在正文「场景」块里的稿子，
   这一维会拿 0——那不是误判，是这类稿子本来就没在镜头层面交代空间。
   但反过来说，**它量不到"同一空间里的调度变化"**：一个人在同一个客厅
   从门口走到窗边再走到沙发，空间分是 0。

## 五、用法

```bash
python engine/dramakit.py quality <分镜表.md>
python engine/dramakit.py quality <分镜表.md> --json
python engine/dramakit.py quality <分镜表.md> --form motion_comic --mode ai
```

`--form` 不传时按文件所在项目的 `overrides.toml` / `project.json` 推断。
形态只影响 `[story.*]` 里被形态覆盖的阈值，不影响五维的定义。

## 六、判据必须能被语料证伪

`_test/quality_corpus.json` 是这把尺子的证伪语料。纪律：

- 好稿必须 ≥ `min`，差稿必须 ≤ `max`，**两组区间不许重叠**；
- 重叠说明尺子分不开好坏，等于没尺子，判据要重做；
- 改 `[story]` 任何阈值或词表，必须重跑 `selftest` 的 P 组。

P 组除了跑语料，还逐维做定向证伪——抽掉全部事件词后事件密度必须归零、
塞进事件词后必须上升、同源切片必须只算一处、旁白点题必须扣分。
只测"好稿高分"是假保护：判据写成"永远满分"也能过。

### 怎么加语料

1. 把样本放进 `_test/quality/`，命名带判断（`好样本-xxx.md` / `坏样本-xxx.md`）；
2. 在 `_test/quality_corpus.json` 里登记 `path` / `form` / `min` 或 `max` / `why`；
3. `why` 必须写清**为什么这份样本该落在这个区间**，不许写"因为跑出来是这个数"；
4. 跑 `selftest`，P 组必须全绿。

加完语料如果发现新样本和旧样本区间重叠，**先怀疑判据，不要调区间**。
