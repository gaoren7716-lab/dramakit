# 规格规范

> 同一部片投不同平台，规格不一样。规格错了，要么被裁掉字幕，要么进不了流量池。
> 这些都是**可机械核对**的：画幅是比例、时长是秒数、安全区是像素占比。

## 一、平台规格

| 平台 | 画幅 | 时长档 | 测重点 |
|---|---|---|---|
| 通用竖屏 | 9:16 | 30-180s | 兜底 |
| 抖音 | 9:16 | 60-180s | 微短剧，竖屏为主 |
| 红果短剧 | 9:16 | 60-120s | 免费+广告分账，前 3 集定生死 |
| 快手 | 9:16 | 45-150s | 社区黏性 |
| 优酷（横屏） | 16:9 | 300-900s | 单集更长 |
| B站 | 16:9 | 60-600s | 横屏 |

**安全区**：平台 UI 会盖住画面顶部与底部。竖屏一般顶部 12%、底部 20% 不可放关键信息
（字幕、台标、关键道具）。横屏则窄得多（上 5%、下 8%）。

时长档与安全区都可机械核对。**画幅构图本身判不了**——那是人的事。

## 二、生成后端能力

| 后端 | 单镜上限 | 提示词上限 | 参考图 | 多镜头 | 音频 | 首尾帧 |
|---|---|---|---|---|---|---|
| 默认 | 8s | 1500 字 | 3 张 | 否 | — | — |
| Seedance 系 | 10s | 1500 字 | 4 张 | 是 | 是 | — |
| 通义万相 Wan 系 | 5s | 1200 字 | 3 张 | 是 | 是 | — |
| 可灵 Kling | 10s | 1500 字 | 2 张 | — | — | 是 |
| Veo | 8s | 1500 字 | 3 张 | — | — | 是 |

**超限必须拒绝，不得截断后调上游。** 模型吐不出来就是吐不出来。
把一个超长的镜头悄悄拆短或把超字数的提示词截一半再发，
等于让上游的不确定性静默变成下游的错误结论——这是最贵的一类错。

⚠️ **能力会升级，投产前必须重新核验**。表里的数字是"已知值"，不是永久事实。

## 三、合规

发布前必过三件，全部机械可判：

1. **AIGC 标识**：AI 生成合成内容必须显式标识（国内发布硬要求）。
   标识要写进交付稿的基本信息块。真人实拍可关（`--live-shoot`）。
2. **未成年人题材**：命中术语即提示"不拍受害细节、不给加害过程"。
   判据只判"有没有触碰"，具体写法交人。
3. **敏感 / 违规表达**：
   - 违规词（政策红线）→ 阻断
   - 敏感词（影射真实主体、具体自伤手段、平台黑话）→ 警告

⚠️ **敏感词只收有明确指向的多字短语**。收单字（"表""局""师"）会命中
"手表""表达""局面"这类日常词，产生大量误报。误报多了人就整个关掉这一项，
等于没有。**宁可漏，不可吵。**

## 四、跨集一致性（连载专用）

单集好做，连载会崩。到第 20-30 集人设飘、伏笔丢、时间轴对不上，
但每一集单看都对。**崩溃的真实形态是文件与文件互相矛盾。**

台账放项目根 `continuity.md`，四张表（时间轴 / 角色 / 场景 / 伏笔）。

判据（全部确定性可算，无一项需要读剧本）：

| 组 | 判据 |
|---|---|
| T 时间轴 | 集号连续无跳号；相邻集时点重复须标"并行" |
| C 角色 | ID 唯一；换装必须显式声明；出场角色必须已登记 |
| S 场景 | ID 唯一；场景必须登记 |
| F 伏笔 | 埋点早于回收点；回收点必须真实存在；状态与回收点一致 |
| X 引用 | 禁止悬空引用 |

⚠️ **为什么机械检查在这里特别值钱**：人复核时逐集读，读到第 18 集
已经忘了第 3 集登记过什么。只有台账能记住，而台账需要机器来对账。
